# HARDSET — Appendix B: Definitions, Fixed Core & Decision Vocabulary

## Terminology

| Term | Operational definition |
|---|---|
| **Hard Set** | Actual working set sufficiently challenging for intended role, with repeatable technique; warm-up not counted. |
| **RIR** | Estimated technically valid reps remaining with same standard; not an exact biological value. |
| **0 RIR** | Cannot complete another correct rep; no deliberate failed attempt required. |
| **Lead Set** | First Hard Set of exercise; main progression signal. |
| **Supporting Set** | Later Hard Set used to check quality and repeated capacity. |
| **Adaptive Dual-Set** | 2 Hard Sets default per exercise, 1 or 3 when justified; more not forbidden if independently justified. |
| **Movement Tag** | Main pattern/function classification of an exercise. |
| **Compound Pattern** | Multi-joint movement organization family. |
| **Targeted Function** | Focused local muscle-function movement family. |
| **P / Primary** | Significant direct principal target of a set. |
| **S / Secondary** | Meaningful indirect contributor, subordinate to a primary target. |
| **—** | No meaningful stimulus claimed. |
| **? / S?** | Uncertain stimulus; not counted for exposure validation. |
| **Exposure** | A session with ≥1 meaningful P or credible S Hard Set for area; one per area per session. |
| **Fixed Core** | The 12 standard reporting areas, not a full anatomical atlas. |
| **Functional Note** | Description of important variation inside broad reporting area. |
| **Functional Override** | Additional user-specific muscle/function target, outside Fixed Core, inheriting requirements when active. |
| **Priority / Standard / Optional** | Allocation priority; not fixed weekly series numbers. |
| **Development / Maintenance** | Desired adaptation in the current period; independent of Priority. |
| **Baseline + Response** | Start with justified weekly dose and adjust based on quality of response. |
| **Weekly Stimulus Ledger** | P sets, separate S work, session exposures, training response. |
| **Focus Block** | Optional period of deliberate targeted emphasis, not mandatory mesocycle. |
| **Deload** | Short intentional reduction of training stress for fatigue management. |
| **Structural Validity** | The program as built matches declared rules/constraints. |
| **Adaptive Adequacy** | Real results support that program dose serves actual goal. |
| **Evidence-Limited Evaluation** | Claims are restricted to outcomes actually measured. |

## Fixed Core map

**Upper Push:** Chest; Lateral Delts; Elbow Extensors.  
**Upper Pull:** Back; Rear Delts; Elbow Flexors.  
**Lower:** Quadriceps; Hamstrings; Glutes; Hip Adductors; Calves.  
**Trunk:** Trunk Musculature.

The labels map training responsibility, not a proof of uniform development. Wide areas may require Functional Notes. Functional Overrides do not silently redefine the fixed map.

## Correct use of P/S

- Horizontal press may be **Chest P**, **Elbow Extensors S** depending on technique and intended stimulus; not necessarily Lateral Delts S.
- A rear-delt isolation may be **Rear Delts P**.
- A leg curl may be **Hamstrings P**, while a knee-dominant leg press is often **Quadriceps P**; specific versions require assessment.
- A generic 'compound' entry should **not** automatically credit every anatomical contributor.
- Trunk stabilization under external load is not automatically a Trunk Musculature P or even a credible S exposure.

These are **illustrations requiring review**, not a database of universal biomechanical truths.
